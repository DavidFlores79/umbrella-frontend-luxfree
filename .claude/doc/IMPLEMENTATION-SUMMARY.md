## Key Decisions Made

| Decision | Choice | Rationale |
|----------|--------|-----------|
| CSS Framework | Tailwind CSS | Utility-first, small bundle, native dark mode |
| Chart Library | ng2-charts | Best Angular 20 support, type-safe wrapper |
| Table Solution | Custom Component | Full control, Tailwind integration, simpler |
| Form Validation | Submit-only | Reduces noise, better UX, cleaner code |
| Dark Mode | Tailwind Class Strategy | Native, easy toggle, persistent, no library |
| State Management | RxJS BehaviorSubject | Fits project architecture, reactive, no signals |
| Component Architecture | Standalone | Angular 20 best practice, no NgModules |

## Quick Start (TL;DR)

1. **Install deps**:
   ```bash
   npm install -D tailwindcss postcss autoprefixer chart.js ng2-charts
   npx tailwindcss init -p
   ```

2. **Copy Tailwind config**:
   - Copy entire content from `.claude/doc/tailwind-config-reference.js`
   - Paste into `/tailwind.config.js`

3. **Update styles.css**:
   ```css
   @tailwind base;
   @tailwind components;
   @tailwind utilities;
   ```

4. **Create theme service**:
   - Copy code from quick-reference-guide.md section 2
   - Place in `/src/app/core/services/theme.service.ts`
   - Add to `app.config.ts` providers

5. **Create components**:
   - Pick any component from `component-blueprints.md`
   - Create directory: `/src/app/shared/components/{type}/{name}/`
   - Copy TypeScript file: `{name}.component.ts`
   - Copy HTML file: `{name}.component.html` (from template)
   - Test: `npm start` and view in browser

6. **Use in features**:
   ```typescript
   import { CardComponent, FormInputComponent } from '@shared/components';

   @Component({
     standalone: true,
     imports: [CardComponent, FormInputComponent]
   })
   export class MyFeature {}
   ```

## Common Gotchas & Solutions

### Issue: Tailwind CSS not applied
**Solution**:
- Ensure `content` array in tailwind.config.js includes `./src/**/*.{html,ts}`
- Rebuild: `npm start`
- Check PostCSS is installed: `npm list postcss`

### Issue: Dark mode toggle not working
**Solution**:
- Verify ThemeService is in app.config.ts providers
- Check browser DevTools: `document.documentElement.classList` should have 'dark'
- Check localStorage: `localStorage.getItem('theme')`

### Issue: Form errors show too early
**Solution**:
- Use submit-only validation pattern from quick-reference
- Only show errors when: `submitted || control.touched`
- Don't validate on keystroke in form submit scenario

### Issue: Components not found in imports
**Solution**:
- Verify all components are `standalone: true`
- Import directly: `import { CardComponent } from '@shared/components'`
- Or export from barrel file: `export * from './card.component'`

### Issue: Styling conflicts with existing CSS
**Solution**:
- Use Tailwind @apply instead of custom CSS
- Avoid specificity wars - trust Tailwind precedence
- Use CSS layers: `@layer components { ... }`

## Performance Optimization Tips

1. **Lazy Load Charts**: Only load Chart.js when chart component visible
2. **Virtual Scrolling**: For large tables, use CDK virtual scroll
3. **OnPush Change Detection**: Use `ChangeDetectionStrategy.OnPush` on components
4. **Async Pipe**: Always use `| async` in templates, never manual subscribe
5. **Code Splitting**: Feature modules lazy loaded automatically
6. **Tailwind Purging**: JIT mode purges unused CSS automatically

## Component Import Pattern

All components are standalone, so no need for NgModule:

```typescript
import { Component } from '@angular/core';
import { CommonModule } from '@angular/common';
import { ReactiveFormsModule } from '@angular/forms';
import {
  CardComponent,
  FormInputComponent,
  DataTableComponent,
  SkeletonComponent,
  BadgeComponent
} from '@shared/components';

@Component({
  selector: 'app-my-feature',
  standalone: true,
  imports: [
    CommonModule,
    ReactiveFormsModule,
    CardComponent,
    FormInputComponent,
    DataTableComponent,
    SkeletonComponent,
    BadgeComponent
  ],
  template: `<!-- Your template -->`
})
export class MyFeatureComponent {}
```
